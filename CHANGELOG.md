## [0.1.0]

Phase 1 — the core.

### Added
- Chrome extension (Manifest V3) for WhatsApp Web.
- Draft replies from the selected message plus your points, using Google Gemini.
- Tone nudges: Shorter, Warmer, Firmer.
- Insert into the message box, with clipboard fallback.
- Settings page: API key, model, style prompt, default tone, insert mode.
- Shortcuts: Alt+R (open), Alt+G (generate), Alt+I (insert).
